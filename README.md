# Informação:
Como tema de nossa atividade, decidimos criar uma página de uma concessionária de veículos que nomeamos "Cuiudos".

O arquivo principal, da página inicial, é o "cuiudos.html". Outros arquivos como "cuiudos-jeep.html" ou "cuiudos-lancer.html" são páginas específicas voltadas para os carros selecionados. A pasta também possui as imagens utilizadas para os carros e a loja.

Na página inicial, há a imagem da frente da loja e botões com os nomes dos carros, que estão separados por categorias. Ao clicar no carro desejado, o usuário será enviado para a página do carro selecionado, contendo sua foto, informações técnicas e seu valor. Para retornar para a página inicial, há um botão escrito "Voltar para a página inicial"
